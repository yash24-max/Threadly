# Roadmap

Roadmap is pull-driven. Only build Phase N+1 once Phase N has real users asking for it.

## Phase 0 — Chatbot Builder + Website Widget (current)
**Status:** Building  
**Ship when:** 5+ paying or beta customers using it

- Visual flow builder
- AI reply with RAG + knowledge base
- Embeddable widget
- Conversation dashboard + analytics
- Human handoff

## Phase 1 — Omnichannel Inbox
**Trigger:** 5–10 paying Phase 0 customers

- WhatsApp Business API integration
- Instagram DM integration
- Facebook Messenger
- Telegram
- Unified inbox — all channels in one view
- Shared customer thread with cross-channel memory

## Phase 2 — CRM Lite
**Trigger:** Inbox is stable, users asking for contact history

- Contacts (auto-created from conversations)
- Tags, notes, conversation timeline
- Simple pipeline (lead → qualified → customer)
- Contact search + export

## Phase 3 — Automation & AI Copilots
**Trigger:** Users with high conversation volumes

- Workflow automation builder (trigger → condition → action)
- AI summarization of conversations
- Sentiment analysis + flagging
- Suggested replies for human agents
- Broadcast / campaign sends (WhatsApp template messages)

## Phase 4 — Full CRM + Voice
**Trigger:** Enterprise / high-ACV customers

- Deals, tickets, SLA management
- Voice AI agents (phone)
- Appointment booking integration
- Vertical templates (clinic, real estate, education)
- White-label option
- On-premise deploy option
